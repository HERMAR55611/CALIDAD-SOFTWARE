# 🧪 Proyecto Integrador – Calidad de Software

## 📌 Descripción del Proyecto
El presente proyecto tiene como objetivo aplicar técnicas de aseguramiento de calidad de software sobre una aplicación web de comercio electrónico.

Se utiliza la plataforma:
👉 https://automationexercise.com/

como entorno de pruebas (SUT - System Under Test), modelando conceptualmente una **tienda de mugs personalizados**, con el fin de evaluar funcionalidades clave como autenticación, navegación de productos, carrito de compras y proceso de checkout.

---

## 🎯 Objetivo
Demostrar el dominio de pruebas de software mediante la implementación de:

- Planificación de pruebas
- Casos de prueba funcionales
- Pruebas de rendimiento
- Automatización de pruebas
- Análisis de resultados

---

## 🛠️ Herramientas Utilizadas

- Apache JMeter → Pruebas de rendimiento
- Selenium WebDriver → Automatización web
- JUnit & Mockito → Pruebas unitarias
- Git & GitHub → Control de versiones

---

## 📋 Alcance del Proyecto

Se evaluaron los siguientes módulos del sistema:

- Registro de usuarios
- Inicio de sesión
- Visualización de productos
- Gestión del carrito
- Proceso de compra

---

## 🧪 Tipos de Pruebas Implementadas

- Pruebas funcionales
- Pruebas de rendimiento
- Pruebas automatizadas

---

## 📊 Resultados de Pruebas de Rendimiento

Se ejecutaron pruebas con 50 usuarios concurrentes utilizando Apache JMeter.

**Resultados obtenidos:**

- Tiempo promedio: 370 ms
- Error %: 0.00%
- Throughput: 10.4 solicitudes/segundo

Estos resultados indican que el sistema presenta un comportamiento estable y eficiente bajo carga moderada.
